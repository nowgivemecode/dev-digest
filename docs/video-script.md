# Алгоритм відео: ДЗ L05 (1–3 хв)

## Підготовка (до запису)

1. Запустити стек: `./scripts/dev.sh`
2. Відкрити DevDigest у браузері → будь-який репо → будь-який PR
3. Переконатись що агент існує і у нього є прикріплені docs (або прикріпити зараз)

---

## Запис

### 1. Project Context у сайдбарі

- У лівому сайдбарі (секція **Workspace**) клікнути **Project Context**
- Показати список документів: шляхи, bucket (server / client / docs / …), кількість токенів
- Клікнути на один документ → праворуч відкривається preview тексту
- Показати лічильник прикріплених файлів в агента: 0 → прикріпити 1 файл → 1 → прикріпити ще один → 2

### 2. Logs + Prompt Assembly (контекст в промпті)

- Відкрити будь-який PR → запустити Review
- Перейти у **Logs** → знайти рядок `Project context: 1 spec(s) injected — file.md (~NNN tok)`
- Відкрити вкладку **Prompt Assembly** → показати секцію **Project context (dynamic)** з вмістом прикріпленого `.md` файлу

### 3. Skills — вкладка Context

- Відкрити будь-який **Skill** → вкладка **Context**
- Прикріпити 2 файли до скіла
- Показати що агент має 1 файл + скіл має 2 файли → разом **3 файли** у промпті

### 4. PR Brief картка

- Перейти на PR → вкладка **Overview**
- Показати badge ризику: **high / medium / low** — виділений кольором
- Показати блок **What** + **Why**
- У **Review Focus** клікнути на файл → відкрилась вкладка **Files Changed** на цьому файлі
- Натиснути **↻ Recompute** → skeleton → картка оновилась

---

## Порядок: 1 → 2 → 3 → 4. Всього 1–3 хв.
